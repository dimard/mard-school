## Mengapa Menu Tidak Terlihat?

Menu PPDB ada di **paling bawah sidebar**. Anda perlu **scroll ke bawah** untuk melihatnya!

### Cara Melihat Menu PPDB:

1. **Login sebagai admin**
2. **Scroll sidebar ke bawah** (section "Content & Settings" ada di paling bawah)
3. Menu akan muncul setelah "News Management"

## Alternatif: Akses Langsung

Jika tidak ingin scroll, langsung akses URL:
```
http://localhost:8080/admin/ppdb
```

**Note**: Aplikasi berjalan di port **8080** (via `php spark serve`), bukan port 80.
